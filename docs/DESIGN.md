# 小小黑洞视觉约定

[返回项目首页](../README.md) · [产品说明](PRODUCT.md)

## 场景
全屏正交视角的低多边形世界。小镇使用粉彩建筑、运河与果园；森林使用溪流、营地、蘑菇与木屋；赛博朋克都市使用深色地面、霓虹线条与未来建筑。每张地图由不同区域组成，界面沿四周排列，为黑洞保留中央活动空间。

## 色彩

- 天空与页面底色：`#e4edf0`
- 正文：`#283440`
- 次要文字：`#566b76`
- 操作与成长反馈：`#7055cd`
- 植被与草地：`#78a989`、`#a9c5b7`
- 建筑与点缀：`#e4c8a6`、`#c8c1d6`、`#eec970`

## 字体
Noto Sans SC。标题采用 900 字重，正文与提示采用 400–600 字重；数字保持等宽数位，便于观察尺寸和进度。

## 布局与交互
左上显示名称，右上放置音效与暂停。开始页左侧以「小小黑洞」作为主标题，下方依次排列模式选择与开始按钮。文字区域使用柔边浅色底，说明文字采用加深色与 12px 字号，保持与场景的清晰对比。底部中央呈现成长和清空进度。窄屏将操作提示与重开放在进度下方。紫色洞口、下落动画与连吃反馈承担主要表现力。

## 状态
开始前显示模式选择、地图选择区和音效开关。地图以「小镇 / 森林 / 霓虹」的单行轻量选项呈现，使用原有淡紫选中态、12px 文字和圆角，不增加面板背景。点击区域保留 44px 高度，原生单选框支持方向键切换与焦点提示。首页不展示主题介绍、尺寸、物品数或重复规则；开始按钮保持主操作层级。好友大厅仅房主可选图，客人显示当前地图名称。深色地图仅将场景外围文字改为浅色，菜单文字仍使用柔边浅底上的深色。窄屏或低矮窗口仅滚动内容区，主标题与模式栏保持原位。进入游戏后显示进度、重开与暂停控件，并移除模式选择区域的交互焦点。倒计时、升级、连吃与暂停通知共用纵向反馈区，长文案自动换行，各条提示按实际高度排列。暂停与重新开始使用原生对话框。减少动态效果偏好会关闭装饰粒子与界面过渡；决定碰撞与落点的物理姿态仍保持一致。

房主暂停时所有人共享同一冻结状态，客人显示等待继续的提示。洞口穿透全部地表层，下面显示暗色井壁与深处背景；物体保留尺寸，通过重力和实际剩余支撑点产生倾倒、滑落与卡边。展示帧对房主发来的位置、四元数及洞口使用同一时间轴插值，不跟随洞主吸附或按固定时长隐藏。

自由、限时与好友联机通过同一组分段按钮切换。限时将倒计时固定在顶部中央，最后 20 秒使用暖红色提示。好友房在左侧呈现邀请、成员和准备状态，开局后收起房间面板，右上方展示实时排名。玩家洞口与排名色点保持一致，结算沿用同一份排序。

三个模式共用主标题、装饰线和模式栏的位置与字号，下方内容区呈现各自的操作。好友大厅延续相同主标题与左侧对齐线。主按钮沿用统一的高度、内边距和圆角；表单与成员列表在可用高度内滚动。

## 地图浏览
地图入口显示当前名称与真实场景缩略图。展开后浏览纵向单选列表；桌面优先放在入口右侧，窄屏根据空间放在入口上方或下方。列表独立滚动，地图增加时保持入口尺寸。原生 popover 处理外部点击、Escape 和焦点返回，原生 radio 提供方向键选择。好友房由房主选图，客人显示当前地图名称。

## 地图主题与场景
地图声明明暗主题，共用界面变量统一控制文字、表面、输入框、选中态、滚动条、HUD 与弹窗。日间场景采用柔边浅底；霓虹都市采用深蓝底和浅色文字，主操作保留紫色。

小镇以暖色建筑与柔和日光形成街区层次。森林采用连续曲线溪流、自然岸线、成片树群、林间空地与沿路木屋。都市将高塔偏向外围，商店与招牌集中在商业区；道路之间留出安静区域，局部灯带、窗户和车灯使用发光材质。地表与发光模型继续按材质合并、实例化渲染。
