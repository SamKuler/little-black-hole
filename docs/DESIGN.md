# 小小黑洞视觉约定

[返回项目首页](../README.md) · [产品说明](PRODUCT.md)

## 场景
全屏正交视角的低多边形小镇。道路、植被与粉彩建筑构成游戏主体；界面沿四周排列，为黑洞保留中央活动空间。

## 色彩

- 天空与页面底色：`#e4edf0`
- 正文：`#283440`
- 次要文字：`#566b76`
- 操作与成长反馈：`#7055cd`
- 植被与草地：`#78a989`、`#a9c5b7`
- 建筑与点缀：`#e4c8a6`、`#c8c1d6`、`#eec970`

## 字体
Noto Sans SC。标题采用 900 字重，正文与提示采用 400–600 字重；数字保持等宽数位，便于观察尺寸和进度。

## 布局与交互
左上显示名称，右上放置音效与暂停。开始页左侧以「小小黑洞」作为主标题，下方依次排列模式选择与开始按钮。文字区域使用柔边浅色底，说明文字采用加深色与 12px 字号，保持与场景的清晰对比。底部中央呈现成长和清空进度。窄屏将操作提示与重开放在进度下方。紫色洞口、下落动画与连吃反馈承担主要表现力。

## 状态
开始前显示模式选择和音效开关，有多张地图时显示地图选择。进入游戏后显示进度、重开与暂停控件，并移除模式选择区域的交互焦点。暂停与重新开始使用原生对话框。减少动态效果偏好会关闭粒子、倾倒与界面过渡。

房主暂停时所有人共享同一冻结状态，客人显示等待继续的提示。物体保留尺寸、向洞口倾斜并加速下落，下落时长由模型高度与占地半径共同决定；展示帧在状态快照之间连续推进。

自由、限时与好友联机通过同一组分段按钮切换。限时将倒计时固定在顶部中央，最后 20 秒使用暖红色提示。好友房在左侧呈现邀请、成员和准备状态，开局后收起房间面板，右上方展示实时排名。玩家洞口与排名色点保持一致，结算沿用同一份排序。

三个模式共用主标题、装饰线和模式栏的位置与字号，下方内容区呈现各自的操作。好友大厅延续相同主标题、左侧对齐线与柔边浅底。主按钮沿用统一的高度、内边距和圆角；表单与成员列表在可用高度内滚动。
