# 洞口物理

洞口在碰撞与渲染中都移除圆形区域内的地面。物体保持原尺寸，由重力、支撑接触与摩擦产生移动和力矩；没有朝洞口中心吸附、缩小或按时长吞噬的动画。

## 模型与范围

- 使用固定版本 cannon-es 0.20.0 的刚体积分、四元数、惯性和约束求解器；自定义圆孔地面的接触生成
- 每类物品由少量凸体组成：树干与树冠、长椅腿与座面、车轮与车身、建筑墙体与屋顶分别参与接触
- 质量中心与惯性是游戏用近似值，装饰细节不逐三角形碰撞；完整穿越判定额外使用模型尺寸包络，避免装饰部分尚未落完就计分
- 地面是 0.25 米厚的水平薄层。移动的洞沿会推挤仍穿过薄层的物体，并在接触点产生力矩；没有接触时不会跟随。完全穿过薄层后，不再被移动的洞壁拖动
- 暂不模拟物体之间的碰撞、堆叠、破碎或可变形地形；不同物体可能彼此穿过

## 支撑与边缘

洞口内不生成地面接触。洞外的凸体顶点、凸体边与圆周交点、底面内部和圆周采样保留支撑，支撑力在接触位置施加，因此偏心支撑会产生力矩。大物体可以跨在洞口两侧，树冠或车身也可能卡边。最多四个洞口取并集，重叠区域不保留内部洞壁。

洞壁接触使用各自洞口的法向速度，而不是让整个地面移动，也不是把物体位置绑定到洞口。接触约束只推不拉；退开的洞沿、被另一个洞口覆盖的内部边界不会吸附物体。仅在地面薄层内采样侧向接触，优先通过真实洞壁接触解决穿透，不再把薄层下方的物体底面当作同时向上推的支架。

车轮、车身、树干和树冠使用整个复合刚体的高度判断应从薄层哪一侧恢复，避免不同零件受到相反的上下约束而永久夹在地图内。洞口断线消失或位置突变时，以限速的单侧穿透修正恢复；接近完全落入薄层下方的物体继续向下，不重新弹回地面。只有完整模型包络穿过薄层后才计分。

圆周接触采用有限采样和简化凸体，极小的剩余支撑区域并非精确的 CAD 布尔碰撞。修正穿透的速度有上限，避免移动洞口恢复地面时将物体弹飞；边缘可能有轻微穿透或抖动。这是面向几百个低多边形物体的实时接触近似。

## 性能与同步

- 物理固定步长为 1/60 秒；长时间卡顿最多补算 0.5 秒，移动最多补算 0.1 秒，防止恢复页面时跳跃或积压
- 快速洞口运动在固定步长内插值细分，使每次接触生成前的边界位移不超过 0.125 米，最多 16 次；更大的瞬时位置跳变作为重置处理，不转换成巨大的撞击速度。细分不改变累计模拟时间
- 远离洞口的物体不创建刚体，稳定物体休眠；接触检测只配对清醒物体与地面，不进行物体间的平方级搜索
- 单人或联机房主负责全部物理、归属和计分。客人只提交方向输入，接收位置与四元数
- 洞口和物体共享快照插值时间轴。完成时短暂保留最终姿态，让画面先完成穿越；之后仅同步完成 ID
- 进入洞口时记录唯一归属；若重新回到地面，归属解除。仅在整个物体低于地面薄层后计分，暂停和结算不再推进刚体
- 联机协议前缀升级至 v4，旧版定时下落客户端不能加入新版物理房间

## 验证

运行 npm test 与 npm run build。可用 npm run benchmark:physics 复现小镇种子 42、566 件物体的单洞、四个初始洞口与四个大洞口 CPU 性能诊断；该诊断不作为 CI 时间阈值，也不代表浏览器帧率。测试覆盖无支撑加速、部分支撑力矩、大物体架桥、自然下落及半入洞汽车的双轴双向移动、快速运动、退开不吸附、树干推挤与树冠卡边、洞口消失和位置重置、多洞并集隐藏内部运动边界、完全落下后不拖动、完整穿越、全部物品类型、固定步长累计、暂停、唯一计分、快照隔离及渲染掩膜。

真实浏览器仍需检查洞缘遮挡、阴影、着色器编译、低端手机帧率与两端联机画面。Node 几何与着色器源测试不能替代 GPU 验收。
