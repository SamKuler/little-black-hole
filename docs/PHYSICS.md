# 洞口物理

洞口在碰撞与渲染中都移除圆形区域内的地面。物体保持原尺寸，由重力、支撑接触与摩擦产生移动和力矩；没有朝洞口中心吸附、缩小或按时长吞噬的动画。

## 模型与范围

- 使用固定版本 cannon-es 0.20.0 的刚体积分、四元数、惯性与 SPOOK 接触方程；自定义圆孔地面接触与受法向载荷约束的顺序冲量求解
- 每类物品由少量凸体组成：树干与树冠、长椅腿与座面、车轮与车身、建筑墙体与屋顶分别参与接触
- 质量中心与惯性是游戏用近似值，装饰细节不逐三角形碰撞；完整穿越判定额外使用模型尺寸包络（包括石子、灌木原点下方的可见几何），避免倾斜或倒置后装饰部分尚未落完就计分
- 地面是 0.25 米厚的水平薄层。移动的洞沿会推挤仍穿过薄层的物体，并在接触点产生力矩；没有接触时不会跟随。完全穿过薄层后，不再被移动的洞壁拖动
- 暂不模拟物体之间的碰撞、堆叠、破碎或可变形地形；不同物体可能彼此穿过

## 支撑与边缘

洞口内不生成地面接触。洞外的凸体顶点、凸体边与圆周交点、底面内部和圆周采样保留支撑，支撑力在接触位置施加，因此偏心支撑会产生力矩。大物体或倾斜后的物体可以跨在洞口两侧。是否能通过取决于当前姿态与真实剩余支撑，不能只比较直立时的半径；不以等待时长强行吞噬。最多四个洞口取并集，重叠区域不保留内部洞壁。

洞壁接触使用各自洞口的法向速度，而不是让整个地面移动，也不是把物体位置绑定到洞口。接触约束只推不拉；退开的洞沿、被另一个洞口覆盖的内部边界不会吸附物体。仅在地面薄层内采样侧向接触；低于顶沿的圆周交点是竖直洞壁，不是向上的台阶。先裁出凸体与薄层相交的截面：若该截面完全落在一个或多个洞口的并集内，就没有地面接触，不能用几米深的底面虚构支撑。并集检查覆盖凸截面的边界区间，并检查圆周交点以保留内部的真实支撑岛。

车轮、车身、树干和树冠使用整个复合刚体的高度判断应从薄层哪一侧恢复，避免不同零件受到相反的上下约束而永久夹在地图内。洞口断线消失或位置突变时，以限速的单侧穿透修正恢复；接近完全落入薄层下方的物体继续向下，不重新弹回地面。只有完整模型包络穿过薄层后才计分。

## 摩擦与穿透恢复

法向冲量只推不拉。两个单位切向共同受 `|Jt| <= μ Jn` 的圆形摩擦预算约束，预算来自本次接触实际求出的法向冲量，不是按物体总重量分配给每个零件的独立摩擦力。没有法向载荷的洞壁不能靠摩擦把物体挂住。切向对使用相同有效质量步长一起更新，避免任意切向轴的选择改变偏心接触的摩擦方向。冲量除以实际子步时长才是报告的力。

穿透恢复使用单独的法向伪速度，仅修正位置与姿态，不写入真实线速度、角速度或摩擦预算。这样恢复重叠时不会产生额外的摩擦锁死或把修正变成弹射速度。每次接触误差限幅，修正中的物体保持清醒，数值残差不会阻止正常休眠。这是使用当前接触雅可比的线性化 split-impulse 修正，不是每轮重建几何的完整非线性求解。

圆周接触采用有限采样和简化凸体，极小的剩余支撑区域并非精确的 CAD 布尔碰撞。修正穿透的速度有上限，避免移动洞口恢复地面时将物体弹飞；边缘可能有轻微穿透或抖动。这是面向几百个低多边形物体的实时接触近似。

## 洞内可见性

洞壁和洞底保留真实的凹入深度，但只显示视线经过地面洞口并集的部分。地图底座比洞体浅，不能单靠有限地图的侧面遮挡，否则靠近边界时会从地图下方看到洞体。着色器将视线与 `y=0` 平面相交，再检查圆孔并集；正交相机使用平行视线，不把每个片元连向相机位置。洞壁仍单独移除重叠洞口的内部墙面，洞底不套用地面的反向裁剪。此可见性规则不改变活动边界、碰撞、计分或地形厚度，也不增加渲染通道。

内缘和物体使用同一条按片元世界高度计算的平滑变暗曲线：`y>=0` 保持原有光照，至 `y=-.30` 完全融入黑色，早于完整可见包络穿过 `y=-.31` 后的计分与隐藏。着色器在光照、发光、色调映射、雾和抖动之后衰减最终颜色，避免霓虹或天空雾重新照亮深处；不改变透明度、深度写入和阴影材质。洞底仅保留纯黑背景，不与深处洞壁形成颜色分界，不靠加深几何体或延长客户端动画伪造下落。

## 性能与同步

- 物理固定步长为 1/60 秒；长时间卡顿最多补算 0.5 秒，移动最多补算 0.1 秒，防止恢复页面时跳跃或积压
- 快速洞口运动在固定步长内插值细分，使每次接触生成前的边界位移不超过 0.125 米，最多 16 次；更大的瞬时位置跳变作为重置处理，不转换成巨大的撞击速度。细分不改变累计模拟时间
- 远离洞口的物体不创建刚体，稳定物体休眠；接触检测只配对清醒物体与地面，不进行物体间的平方级搜索
- 单人或联机房主负责全部物理、归属和计分。客人只提交方向输入，接收位置与四元数
- 洞口和物体共享快照插值时间轴。完成时短暂保留最终姿态，让画面先完成穿越；最后一个物体结束比赛时也走完同一插值区间，但不继续模拟或计分。之后仅同步完成 ID
- 进入洞口时记录唯一归属；若重新回到地面，归属解除。仅在整个物体低于地面薄层后计分，暂停和结算不再推进刚体
- 联机协议前缀升级至 v4，旧版定时下落客户端不能加入新版物理房间

## 验证

运行 npm test 与 npm run build。可用 npm run benchmark:physics 复现小镇种子 42、566 件物体的单洞、四个初始洞口与四个大洞口 CPU 性能诊断；该诊断不作为 CI 时间阈值，也不代表浏览器帧率。测试覆盖无支撑加速、部分支撑力矩、大物体架桥、自然下落及半入洞汽车的双轴双向移动、快速运动、退开不吸附、树干推挤、可通过物体长期卡边、洞口消失和位置重置、多洞并集隐藏内部运动边界、完全落下后不拖动、完整穿越、全部物品类型、固定步长累计、暂停、唯一计分、快照隔离及渲染掩膜。

额外回归覆盖摩擦冲量单位与质量/子步缩放、零载荷与退开接触、斜向滑动、偏心接触切向基不变性、摩擦圆上限、穿透恢复与物理冲量隔离、接触池重用、睡眠与增长唤醒、单洞/多洞的深埋底面假支撑，以及 108 组形状、大小比、起始位置和角度的 30 秒长期稳定性检查。长期检查不要求所有物体自动吞噬；真实的双侧支撑仍然保留。全部 22 个渲染模型的包络在直立、倾斜和倒置姿态下都有几何检查。

实现交叉核对：[cannon-es 0.20 求解器](https://github.com/pmndrs/cannon-es/blob/v0.20.0/src/solver/GSSolver.ts)、[接触/摩擦生成](https://github.com/pmndrs/cannon-es/blob/v0.20.0/src/world/Narrowphase.ts)、[Box2D 摩擦模型说明](https://box2d.org/documentation/md_simulation.html)、[Erin Catto 的求解与位置修正说明](https://box2d.org/posts/2024/02/solver2d/)。这些资料说明实现原则，不代表本游戏等同于 Box2D 或完成了全部物理验证。

真实浏览器仍需检查洞缘遮挡、阴影、着色器编译、低端手机帧率与两端联机画面。Node 几何与着色器源测试不能替代 GPU 验收。
